A vending machine's pickup line for a passing human: a thousand snacks vended, never jammed — until you walked past and its coil got stuck on you. One line, spoken by the machine itself, from its own world of snacks, coils and jams.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (one line, under 200 characters).
